## 🚀 Key Features

### User Authentication

*   **Secure Sign Up**: Users can securely create accounts with email and password.
*   **Login**: Existing users can log in to access their account and shopping history.
*   **Profile Management**: Users can manage their profile information.
*   **Forgot and Reset Password**: Users can reset their password in case they forgot.

### Product Browsing & Shopping

*   **Product Catalog**: Browse a diverse range of products.
*   **Search and Filter**: Easily find products using the search bar and various filter options.
*   **Product Details**: View detailed product information, including images, descriptions, and prices.
*   **Add to Cart**: Add products to the shopping cart.
*   **Cart Management**: View, modify, and remove items from the cart.

### Payment & Order Management

*   **Secure Payment**: Secure payment processing via PayPal.
*   **Order Placement**: Place orders and receive confirmation.
*   **Order History**: Users can view their order history.

### Admin Dashboard

*   **Product Management**: Add, edit, and delete products.
*   **Order Management**: View and manage all orders.
*   **User Management**: View and manage user accounts.

## Installation Instructions

To set up the Cool Plaza project on your local machine, follow these step-by-step instructions.

### Prerequisites

Before you begin, ensure you have the following installed:

*   **Node.js**: You can download it from [https://nodejs.org/](https://nodejs.org/).
*   **npm**: npm usually comes with Node.js. You can verify it by running `npm -v` in your terminal.
*   **MongoDB**: Make sure you have MongoDB installed and running. You can download it from [https://www.mongodb.com/](https://www.mongodb.com/).


1.  **Clone the Repository:**
    -   Open your terminal and navigate to the directory where you want to store the project.
    -   Clone the repository using the following command:
        bash git clone https://github.com/dsaha007/CoolPlaza-App
    - Navigate to the backend directory:
        bash cd backend
    - Navigate to the frontend directory:
        bash cd frontend
