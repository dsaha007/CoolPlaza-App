# Cool Plaza - E-commerce Platform

Welcome to Cool Plaza, your ultimate online shopping destination! This project is a full-featured e-commerce platform built using the MERN stack (MongoDB, Express.js, React.js, Node.js). It offers a seamless shopping experience with user-friendly navigation and robust functionalities.

## Live Site

Explore Cool Plaza now: [https://cool-plaza.onrender.com/](https://cool-plaza.onrender.com/)

## Key Features

### User Authentication

-   **Secure Sign Up:** Users can create accounts securely with email and password.
-   **Login:** Existing users can log in to access their account and shopping history.
-   **Profile Management:** Users can manage their profile information.

### Product Browsing

-   **Product Catalog:** Browse through a wide variety of products.
-   **Search and Filter:** Easily find products using the search bar and filter options.
-   **Product Details:** View detailed product information, including images, descriptions, and prices.

### Shopping Cart

-   **Add to Cart:** Add products to the shopping cart.
-   **Cart Management:** View, modify, and remove items from the cart.

### Payment Integration

-   **Secure Payment:** Secure payment processing via PayPal.
-   **Order Placement:** Place orders and get order confirmation.

### Admin Dashboard

-   **Product Management:** Add, edit, and delete products.
-   **Order Management:** View and manage all orders.
-   **User Management:** View and manage user accounts.
